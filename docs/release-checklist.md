# 发布检查清单

> 发布前逐项勾选。任何一项不满足，不得标记为可上线。

## 1. 构建与测试

- [ ] `cd server && mvn test` 全部通过（当前基线 101 个测试）
- [ ] `mvn package` 成功，使用锁定依赖，无 SNAPSHOT 依赖
- [ ] 空数据库执行 Flyway 迁移成功
- [ ] 演示数据未在生产环境加载
- [ ] `cd admin && pnpm typecheck && pnpm build` 通过
- [ ] 管理后台 `dist/` 可正常访问，SPA 路由刷新不 404
- [ ] `cd miniapp && pnpm typecheck` 通过
- [ ] `cd android && ./gradlew :app:assembleRelease` 通过（如发布 Android）
- [ ] Android versionCode/versionName 已更新
- [ ] 小程序在微信开发者工具中编译通过
- [ ] Android APK 在目标真机安装、启动和主流程通过
- [ ] 小程序真机预览通过（如发布真机）
- [ ] 无未解决的高优先级缺陷

## 2. 配置与密钥

- [ ] `SPRING_PROFILES_ACTIVE=prod`
- [ ] `JWT_SECRET` 为独立强随机值（≥32 字符），未使用开发默认值
- [ ] 数据库账号为最小权限账号，密码未进入仓库
- [ ] `WECHAT_APP_ID` / `WECHAT_APP_SECRET` 仅配置在服务端
- [ ] 支付商户号、证书、API v3 Key 仅配置在服务端安全存储
- [ ] `APP_DEV_LOGIN_ENABLED=false`
- [ ] `APP_PAYMENT_MOCK_ENABLED=false`
- [ ] `CORS_ALLOWED_ORIGINS` 为明确 HTTPS 白名单，不使用 `*` + credentials
- [ ] `.env`、`project.config.json`、上传文件、证书未提交
- [ ] 管理员首次初始化密码为强密码，并在初始化后妥善保管

## 3. 数据库

- [ ] 生产库已备份，备份可恢复演练
- [ ] Flyway 历史表与脚本一致，无手工改表
- [ ] 已评估迁移锁表时间与回滚方案
- [ ] 金额字段仍为 `DECIMAL`，未引入浮点计算
- [ ] 订单号/SKU 编码/幂等键唯一索引存在
- [ ] 库存 `CHECK (stock >= 0)` 有效
- [ ] 索引覆盖订单列表、商品列表、购物车、地址等常用查询
- [ ] 演示账号/演示订单未进入生产

## 4. 安全

- [ ] `/api/v1/me/**` 未登录返回 401
- [ ] 普通用户访问 `/api/v1/admin/**` 返回 403
- [ ] 用户不能读取/修改他人购物车、地址、订单
- [ ] 管理员密码使用 BCrypt，未存储明文
- [ ] 禁用用户/管理员的旧令牌立即失效
- [ ] 生产 Swagger 已关闭或限制访问
- [ ] 上传只允许 jpg/png/webp、≤2MB，校验文件内容
- [ ] 上传目录不可执行脚本，文件名随机
- [ ] 登录与下单限流已评估（多实例需替换为 Redis 等共享限流）
- [ ] 日志不包含密码、Token、AppSecret、支付密钥、完整手机号/地址
- [ ] HTTPS 已启用，HSTS/证书有效期已检查
- [ ] Android 生产包已移除 `usesCleartextTraffic`，API 地址为 HTTPS
- [ ] Android 使用正式签名，未使用 debug keystore
- [ ] 错误响应不暴露堆栈
- [ ] SQL 使用参数绑定，无字符串拼接
- [ ] 依赖漏洞扫描已执行（`mvn dependency:tree`、`pnpm audit` 等）

## 5. 用户端功能验收

- [ ] 首页轮播/分类/推荐商品加载，图片失败有占位
- [ ] 分类筛选、分页、空状态、下拉刷新
- [ ] 关键词搜索、最近搜索、无结果状态
- [ ] 商品详情下架/售罄/SKU 失效提示
- [ ] 商品详情收藏、浏览足迹、评价入口可用
- [ ] 搜索热词、中文关键词搜索、销量排序可用
- [ ] 首页新品/热销/推荐只含上架商品
- [ ] 会员积分、等级、积分明细展示正确
- [ ] 客服工单可提交、查看回复
- [ ] 结算页可选优惠券，优惠金额由服务端计算，取消订单释放
- [ ] 运费模板按省份/首件续件/包邮门槛计算正确
- [ ] 开发登录/微信登录按环境配置工作
- [ ] 地址新增/编辑/删除/默认切换
- [ ] 购物车勾选、改数量、删除、合计正确
- [ ] 结算预览金额由服务端计算
- [ ] 提交订单防重复，库存不足整单失败
- [ ] 模拟支付/真实支付（按环境）成功后状态正确
- [ ] 未支付订单可取消，库存只回补一次
- [ ] 待收货订单可确认收货
- [ ] 超时未支付订单自动取消
- [ ] 已支付订单可申请仅退款/退货退款，未支付/已取消不可申请
- [ ] 退款金额由服务端计算，客户端篡改无效
- [ ] 仅退款不回补库存；退货退款确认收货且退款成功后才回补
- [ ] 售后退款失败可重试，不产生假成功
- [ ] 订单列表/详情只展示本人数据
- [ ] Android 端首页、登录、加购、下单、模拟支付/真实支付、订单状态与小程序一致

## 6. 管理后台功能验收

- [ ] 管理员登录、退出、错误密码提示
- [ ] 不同角色只能看到/调用授权菜单与接口
- [ ] 不能禁用自己或最后一个超级管理员
- [ ] 改角色/禁用/重置密码后旧 JWT 失效
- [ ] 管理员新增、重置密码、修改自己密码可用
- [ ] 操作日志可查询，记录操作人/动作/对象/requestId
- [ ] CSV 导出字段与筛选项一致，手机号脱敏，导出动作写日志
- [ ] 仪表盘口径与真实数据一致（无演示伪造）
- [ ] 分类增删改查、排序、启停、删除约束
- [ ] 商品/图片/SKU/库存新增与编辑
- [ ] 上架校验至少一个启用 SKU
- [ ] 已被订单引用的商品不能删除
- [ ] 订单筛选、详情、发货（物流公司/单号）
- [ ] 待付款订单管理员取消并回补库存
- [ ] 售后审核、拒绝、确认收到退货、退款操作可用
- [ ] 库存流水前后值连续，低库存预警可查
- [ ] 已退款订单不能发货
- [ ] 优惠券模板可创建/启停，领取不超发，每人限领 1 张
- [ ] 运费模板可创建/启停/删除限制，商品可绑定
- [ ] 评价可审核/拒绝/回复，公开页只显示已通过
- [ ] 客服工单可筛选/回复/关闭
- [ ] 管理员调整积分不能造成负余额
- [ ] 待发货已支付订单可改地址，已发货不能改
- [ ] 后台备注仅后台可见，保存写操作日志
- [ ] 发票抬头/邮箱必填校验，订单详情可查看
- [ ] 自动确认收货只执行一次，售后中/已退款订单跳过
- [ ] 用户列表手机号脱敏、状态切换
- [ ] 轮播图跳转目标校验
- [ ] 图片上传与访问正常
- [ ] 危险操作二次确认，提交期间防重复

## 7. 微信平台与合规

- [ ] 小程序主体、类目、备案符合要求
- [ ] 隐私保护指引已配置，收集信息与实际一致
- [ ] 服务器 request/upload/download 合法域名已配置 HTTPS
- [ ] 小程序 AppID 与生产环境一致
- [ ] 微信登录 AppSecret 仅服务端持有
- [ ] 支付商户号、证书、回调域名与平台配置一致
- [ ] 用户协议、隐私说明已上线（当前脚手架仅预留入口）
- [ ] 商品、图片、文案无侵权内容
- [ ] 不承诺绕过平台审核或资质要求

## 8. 部署与回滚

- [ ] 服务端进程守护、日志轮转、磁盘/内存告警已配置
- [ ] Nginx 反向代理、超时、上传大小限制与服务端一致
- [ ] 健康检查 `/api/v1/health` 纳入监控
- [ ] 数据库连接池、JVM 参数按容量配置
- [ ] 静态资源与上传目录已挂载/备份
- [ ] 发布顺序：数据库迁移 → 服务端 → 管理后台 → 小程序

## 9. 已知限制（当前版本）

- 真实微信登录未验收，需要 AppID/Secret 与线上域名
- 真实微信支付、回调验签、对账未实现；退款已支持模拟/线下手工登记，真实微信退款待接入，步骤见 [`wechat-integration.md`](./wechat-integration.md)
- 物流轨迹、订阅推送、自动确认收货未实现；接入步骤见 [`logistics-integration.md`](./logistics-integration.md)
- 微信订阅消息/短信未接入，当前通知为站内通知
- Android 端售后/R2 后台能力未补齐（后台为 Web）
- 发票仅记录信息，未接入电子发票开具
- 评价仅文字/评分，未接入评价图片上传
- 优惠券首版每人每模板限领 1 张，未做复杂叠加/阶梯促销
- Android 端 R3/R4 页面（优惠券/评价/收藏/足迹/会员/客服）未补齐
- 搜索使用 MySQL ngram，未接 Elasticsearch/OpenSearch
- 积分仅展示会员等级，首版不抵现、不设过期
- 客服工单无图片附件与消息推送
- CSV 导出单次最多 10000 行，未做异步大文件导出
- 限流为单实例内存实现，多实例需替换
- Redis、对象存储、优惠券、收藏、评价、会员未接入；售后、库存流水、站内通知已落地，优先级与迭代计划见 [`roadmap.md`](./roadmap.md)
- 小程序当前使用原生组件，TDesign 依赖已安装但未使用
- Android 端未接入微信登录/真实微信支付，当前为开发登录 + 模拟支付
- Android 当前仅在模拟器验证，发布前需真机验收
- 演示图片指向 localhost，真机需替换图片域名
